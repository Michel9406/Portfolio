Sobre mim

Sou um Desenvolvedor Full Stack apaixonado por transformar ideias em soluções reais. Com uma sólida base em Java, Spring Boot, React e AWS, minha carreira começou com uma transição para a tecnologia, onde trouxe comigo uma visão estratégica de marketing digital, o que me permite desenvolver soluções focadas no usuário e orientadas por dados.

Formado pela Generation Brasil, participei de projetos colaborativos práticos, liderando o desenvolvimento de APIs REST, sistemas integrados e interfaces responsivas. Um dos destaques da minha trajetória foi o Zurah, um marketplace social que conecta pequenos produtores a restaurantes, impactando diretamente a redução da desigualdade.

Atualmente, estou aprofundando meus conhecimentos em cloud computing e buscando a certificação AWS Practitioner. Meu foco está em criar soluções escaláveis e resilientes, aplicando boas práticas de DevOps para garantir a máxima performance e eficiência.

Resumo Profissional

Hard Skills:
    • Linguagens de Programação JavaScript e TypeScript
    • Frontend: React, HTML5, CSS3 e Tailwind CSS
    • Backend: Java (com Spring Boot), Node.js
    • Banco de Dados: MySQL e MongoDB
    • Ferramentas e Tecnologias: Git, GitHub, Docker, Postman, Insomnia
    • Testes: JUnit (Java), Jest (JS básico)

Além das habilidades técnicas, valorizo o trabalho em equipe, a comunicação eficiente e a colaboração, utilizando metodologias ágeis como Scrum e Kanban. Acredito que esses são aspectos fundamentais para o sucesso de qualquer projeto. Estou ansioso para me juntar a um time dinâmico e inovador, onde possamos crescer juntos e desenvolver soluções incríveis.

Busco oportunidades onde possa crescer, entregar valor real e colaborar com times engajados em fazer tecnologia com propósito.
